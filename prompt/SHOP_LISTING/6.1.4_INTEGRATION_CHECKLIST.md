# Task 6.1.4: Integration Points - Add Migration Calls

## Objective
Integrate `LazyMigration` module into existing handlers where items are accessed.

## Integration Points

### 1. **ShopSellAction.lua** (PRIORITY: HIGH)
- **Location**: `Shops/42.13.1/media/lua/shared/nshopsb42/timers/ShopSellAction.lua#L105-L122`
- **What happens**: Items are retrieved from inventory by ID for selling
- **Migration needed**: Call `Migration.migrateItemIfNeeded(item)` before processing each item
- **When**: Before validating item price or removing from inventory
- **Code change**:
  ```lua
  -- After retrieving item via getItemById()
  local Migration = require("nshopsb42/schema/LazyMigration")
  Migration.migrateItemIfNeeded(item)
  ```

### 2. **PlayerShopServer.lua** (PRIORITY: HIGH)
- **Location**: `Shops/42.13.1/media/lua/server/nshopsb42/PlayerShopServer.lua#L44-L71` (SetItemPrice)
- **What happens**: Item price is set/read from ModData
- **Migration needed**: Call `Migration.migrateItemIfNeeded(item)` before reading ModData
- **When**: Immediately after retrieving item at line 54
- **Code change**:
  ```lua
  local item = player:getInventory():getItemById(itemID)
  if not item then return end
  
  -- Migrate item before accessing/modifying ModData
  local Migration = require("nshopsb42/schema/LazyMigration")
  Migration.migrateItemIfNeeded(item)
  ```

### 3. **BalanceServer.lua** (PRIORITY: MEDIUM)
- **Location**: `Shops/42.13.1/media/lua/server/nshopsb42/balance/BalanceServer.lua#L176-L186` (Deposit function)
- **What happens**: Items are verified to exist in inventory before balance deduction
- **Migration needed**: Migrate items during iteration
- **When**: In the loop checking item existence
- **Code change**:
  ```lua
  local Migration = require("nshopsb42/schema/LazyMigration")
  for i, itemID in ipairs(itemIDs) do
      local item = player:getInventory():getItemById(itemID)
      if not item then ... end
      
      -- Migrate as part of validation
      Migration.migrateItemIfNeeded(item)
      table.insert(itemsToRemove, item)
  end
  ```

### 4. **ShopBuyAction.lua** (PRIORITY: LOW)
- **Location**: `Shops/42.13.1/media/lua/shared/nshopsb42/timers/ShopBuyAction.lua`
- **What happens**: New items are created and added to inventory
- **Migration needed**: Likely NOT needed (new items won't have old deprecated fields)
- **Decision**: Skip unless we find new items somehow have old data
- **Alternative**: Migrate all items in player inventory on purchase completion (safety measure)

### 5. **PlayerShop Container Access** (PRIORITY: MEDIUM)
- **Location**: When player accesses a container (shelf/freezer)
- **What happens**: Container items may have old ModData
- **Migration needed**: Migrate all items in container when it's accessed
- **When**: On container open/access
- **Code change**: Hook into container access and call `Migration.migrateContainer(container)`
