## How It Works

### Migration Flow

1. **Player logs in** → `RequestShopData()` fires → `migratePlayerInventory(player)` runs
   - Iterates all items in player inventory
   - Calls `migrateItemIfNeeded()` on each
   - Logs any items that had deprecated fields
   - Removes old fields and tracks statistics

2. **During gameplay** → When items are accessed via:
   - Setting prices on player shop items
   - Selling items
   - Depositing items for balance
   - Each call checks if item was already migrated (via session cache) and skips if done

3. **Migration is idempotent** - Safe to call multiple times, only logs once per item

### Safety Features

- **Session tracking**: Items marked as migrated avoid repeated logging
- **Field deletion**: Old `price` and `specialCoin` fields are nil'd out (cannot be reused)
- **Statistics**: Migration stats tracked for admin visibility
- **No side effects**: Items are not removed/modified, only ModData cleaned
